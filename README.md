# 工作导航 · Work Nav

纯本地的个人工作网址导航页。无需安装任何环境，无任何网络请求，数据 100% 存在你自己的电脑上。

原生 HTML/CSS/JS，**无构建、无依赖、无 CDN、无后端**。下载下来双击就能用。

> 在线体验：https://workbuddy.link/p/daYUqDSc107pkxRVzF62PG

## 快速开始

### 方式一：直接打开（最简单）

双击 `index.html` 即可使用。已验证 Chromium 系浏览器（Chrome / Edge）在本地文件模式下全部功能正常，包括数据保存和背景图片存储。

### 方式二：本地服务（推荐 Firefox 用户）

Firefox 对 `file://` 协议的限制较多，如遇数据不能保存，改用一行命令起个本地服务：

```bash
cd work-nav
python3 -m http.server 8899
```

然后访问 `http://127.0.0.1:8899`。

## 功能速览

| 功能 | 用法 |
| --- | --- |
| 添加站点 | 右上角「添加站点」，或在分类标题旁点「＋ 添加」；弹窗顶部也直接有「从浏览器书签导入」入口 |
| 收藏夹导入 | 设置 → 数据，或空页面引导，或添加站点弹窗顶部；支持 Chrome / Edge / Firefox / 360 导出的书签 HTML |
| 更换背景 | 设置 → 背景；预设壁纸 / 渐变 / 纯色 / 本地上传 / 图片链接，支持自动轮播 |
| 搜索 | 顶栏搜索框，支持拼音首字母（输入 `tx` 命中「腾讯文档」）；`↑`/`↓` 选结果、回车打开 |
| 站点操作 | 单击打开、右键菜单（编辑/置顶/复制链接/删除）、`Ctrl+点击` 强制新标签页 |
| 分类管理 | 左侧栏新建 / 重命名 / 删除分类，支持两级；点分组标题可折叠 |
| 排序 | 拖拽卡片或侧栏分类调整顺序；也可在设置里按名称 / 访问量 / 最近访问排序 |
| 标签 | 给站点打标签，卡片上直接显示，点标签即筛选 |
| 多选批量 | 顶栏「多选」按钮 → 勾选后批量移动分类 / 置顶 / 删除 |
| 回收站 | 删除的站点进回收站（保留最近 50 条），可随时恢复或彻底删除 |
| 分享只读快照 | 设置 → 数据 → 导出只读快照：生成一个独立 HTML，别人能看不能改 |
| 备份恢复 | 设置 → 数据：导出 JSON、导入 JSON、一键回滚上一次修改 |

## 分享与部署

- **导出只读快照**：把当前数据烤进一个独立 HTML 文件，发给同事即可查看，不需要任何环境，对方也改不了你的数据。导出时会把 CSS/JS 一并内联，单文件可直接双击打开。
- **加到桌面**：项目带 `manifest.webmanifest`，Chrome / Edge / Safari 可「添加到主屏幕」当轻应用使用。注意未注册 Service Worker，因此不算完整离线 PWA。

## 快捷键

| 按键 | 作用 |
| --- | --- |
| `/` 或 `Ctrl+K` | 聚焦搜索框 |
| `↑` / `↓` | 在搜索结果间移动选中 |
| `N` | 新增站点 |
| `Esc` | 关闭弹窗 / 清空搜索 / 退出多选 |
| 表单内 `Ctrl+Enter` | 保存当前站点 |

## 数据与隐私

- **所有数据只存在本机**：站点数据在浏览器 localStorage，背景图片在 IndexedDB。全站没有埋点、没有远程接口。
- 「联网抓取站点图标」默认**关闭**，开启前请知悉这会向第三方域名发起请求。
- **务必定期备份**：清理浏览器数据、无痕模式、更换电脑都会导致数据丢失（设置 → 数据 → 导出 JSON）。
- 本工具**不设密码**，能打开这台电脑的人都能看到全部内容，请勿存放账号密码类信息。

## 从浏览器导出书签

| 浏览器 | 路径 |
| --- | --- |
| Chrome | 书签管理器（`Ctrl+Shift+O`）→ 右上角 ⋮ → 导出书签 |
| Edge | 收藏夹（`Ctrl+Shift+O`）→ 右上角 … → 导出收藏夹 |
| Firefox | 书签库（`Ctrl+Shift+O`）→ 导入和备份 → 导出书签到 HTML |
| 360 | 收藏夹 → 管理收藏夹 → 导出 |

Safari 导出的 plist 格式暂不支持。

## 目录结构

```
work-nav/
├── index.html                 # 唯一入口
├── manifest.webmanifest       # 「添加到桌面」用的 Web App Manifest
├── assets/
│   ├── favicon.svg
│   ├── css/                   # base(主题变量) / layout(布局) / components(组件)
│   └── js/
│       ├── utils.js           # 工具函数（URL 规范化、去重键、防抖…）
│       ├── storage.js         # localStorage + IndexedDB 封装、数据迁移
│       ├── store.js           # 状态管理（单一数据源 + 订阅刷新）
│       ├── bookmark.js        # Netscape 书签 HTML 解析
│       ├── pinyin.js          # 拼音首字母搜索
│       ├── background.js      # 背景系统（压缩、主色提取、轮播）
│       ├── render.js          # 视图渲染
│       └── app.js             # 入口与事件编排
├── portable/
│   └── 工作导航-便携版.html    # 单文件版：CSS/JS 全内联，拷走就能用
└── docs/
    └── 开发文档.md            # 架构、数据结构、设计取舍、踩坑记录
```

无构建、无依赖、无 CDN。修改代码刷新即生效。

## 开发

改完代码刷新页面即可，没有编译步骤。开发文档（`docs/开发文档.md`）里写了模块职责、数据结构、数据迁移策略，以及踩过的坑，动手前值得先扫一遍。

```bash
git clone git@github.com:chongyangli/work-nav.git   # 推荐，SSH
git clone https://github.com/chongyangli/work-nav.git
```

本地起个静态服务就能跑（如 `python -m http.server 8080`）；直接双击 `index.html` 也能用，只是 `manifest.webmanifest` 在 `file://` 下不生效。

仓库统一使用 LF 行尾（见 `.gitattributes`），提交前无需手动处理。
